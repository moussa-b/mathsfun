# 🖼️ Screen-by-Screen Description

## 🏠 Splash Screen
**Purpose:** Welcomes the user with animation.  
**Elements:**
- App logo and fun animation (numbers or mascot)
- Automatically transitions to the next appropriate screen (based on profile count).

---

## 👤 Profile Creation
**Purpose:** Allows parent to create a child profile.  
**Elements:**
- Fields: nickname, class, avatar selector
- Buttons: “Save”, “Back”
**Flow:** On save → navigate to Exercise Type Selection.

---

## 👪 Profile Selector
**Purpose:** Choose which child will play.  
**Elements:**
- List of avatars + nicknames
- “New Profile” button
- (Optional) “Delete” icon
**Flow:** Select profile → Exercise Type Selection.

---

## ➕✖️ Exercise Type Selection
**Purpose:** Choose to revise additions or multiplications.  
**Elements:**
- Buttons: “Additions”, “Multiplications”
- “Change Profile” option

---

## 🧠 Mode Selection
**Purpose:** Choose between revision or exercise mode.  
**Elements:**
- Buttons: “Revision”, “Exercise”

---

## 📘 Revision Mode
**Purpose:** Display tables with answers for learning.  
**Elements:**
- Current table (e.g., “×3”)
- Navigation buttons: previous/next table
- Home button

---

## 🧩 Exercise Mode Type Selection
**Purpose:** Choose question format.  
**Elements:**
- Buttons: “Multiple Choice”, “Direct Input”

---

## 🧠 Exercise A — Multiple Choice
**Purpose:** Practice with 3–4 possible answers.  
**Elements:**
- Question (e.g., 6 × 7 = ?)
- Multiple answer buttons
- Progress indicator
**Feedback:** Correct/incorrect animations and sounds.

---

## ✏️ Exercise B — Direct Input
**Purpose:** Practice by typing the answer.  
**Elements:**
- Question (e.g., 9 + 8 = ?)
- Input field (numeric)
- “Check” and “Next” buttons

---

## 📊 Results Screen
**Purpose:** Show score summary.  
**Elements:**
- Total correct answers
- Mistakes
- Completion time
- Buttons: “Replay”, “Home”, “View Stats”

---

## 📈 Statistics Screen
**Purpose:** Display profile progress.  
**Elements:**
- Avatar, nickname
- Charts or summary stats
- Button: “Home”
